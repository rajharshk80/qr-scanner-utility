# QR Scanner Utility

A simple, lightweight, and fast web-based QR Code Scanner built using HTML, CSS, and JavaScript. It utilizes the `html5-qrcode` library to scan QR codes directly using device camera.

## Features
* 📷 **Real-time Scanning:** Scan QR codes instantly using your device's front or back camera.
* ⚡ **Fast & Lightweight:** Built with pure web technologies without needing heavy desktop software.
* 📱 **Responsive Design:** Works smoothly on both mobile and desktop browsers.

## Tech Stack
* **HTML5**
* **CSS3**
* **JavaScript**
* **Library:** `html5-qrcode` CDN

## How to Run
1. Clone the repository or download the source code files (`index.html` & `script.js`).
2. Open `index.html` in any modern web browser (or use VS Code Live Server).
3. Allow camera permissions when prompted and start scanning QR codes!
